# Koka & Co: The Open Space (3D)

A playful 3D office where AI job-application agents walk between department rooms and hand each finished application in at the Job Center.

This hosted page runs on **simulated demo data**: it contains no real applications, companies or personal information. Drag to rotate, scroll to zoom.

Built with [three.js](https://threejs.org/) (MIT). No build step: open `index.html` through any static server.
